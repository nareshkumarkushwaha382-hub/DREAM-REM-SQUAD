# Dream Rem Squad | DRS

> **"DREAM REM SQUAD WAS HERE."**

Dream Rem Squad (DRS) is an independent, polished worldwide fan community foundation dedicated to Rem and the world of *Re:ZERO - Starting Life in Another World*.

## Project Architecture
This repository contains a clean, high-performance static website built with:
- **HTML5** (Semantic markup, accessibility features, Open Graph metadata)
- **CSS3** (Custom properties/variables, night-sky aesthetic, glassmorphism, responsive grid layouts)
- **Vanilla JavaScript** (Mobile menu navigation, spoiler toggle locks, gallery filters, search bar, lightbox modals, back-to-top button)
- **No Build Process Required** (Works immediately out-of-the-box on static hosting providers like GitHub Pages).
