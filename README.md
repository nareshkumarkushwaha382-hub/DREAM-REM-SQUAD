# 🌙 Dream Rem Squad (DRS)

> **"DREAM REM SQUAD WAS HERE."**

**Dream Rem Squad (DRS)** is a fan-made community project created to give Rem fans a recognizable place to discover, create, discuss, and celebrate the world of *Re:ZERO - Starting Life in Another World*.

DRS is being built with a long-term goal: grow from a small fan project into a welcoming worldwide community with its own identity, creative projects, events, archives, and community culture.

> **Status:** DRS v1 foundation is under development.

---

## 🌙 What is Dream Rem Squad?

DRS is more than a single fan page.

The idea is to create a community hub where fans can:

- Explore a Rem-focused archive
- Discover fan art and wallpapers
- Participate in future community events
- Learn about DRS and its history
- Share creative projects
- Connect through future community platforms
- Enjoy spoiler-aware content organization

DRS is an **independent fan project** and is not an official *Re:ZERO* organization.

---

## 🎯 Mission

> **Build a welcoming worldwide community for people who appreciate Rem and the world of Re:ZERO.**

The project focuses on creativity, respect, responsible fan-content sharing, and a positive community atmosphere.

## 🛡️ Community Principles

DRS aims to maintain a welcoming environment.

Core principles include:

1. Respect other members.
2. Do not harass or bully other fans.
3. Mark spoilers clearly.
4. Credit artists and creators.
5. Do not claim someone else's work as your own.
6. Do not spam.
7. Respect different opinions about characters and the story.
8. Protect personal privacy.
9. Keep community spaces appropriate and welcoming.
10. Follow the rules of the platform being used.

The full rules are available on the website's **Rules** page.

---

## 🎨 Artist Credit Policy

DRS should never present someone else's artwork as DRS-owned work.

When fan artwork is eventually displayed:

- Credit the artist.
- Preserve the original artist identity where appropriate.
- Include a source/link when available and permitted.
- Do not remove artist signatures or watermarks.
- Do not imply that DRS created artwork made by someone else.

The current website uses placeholders where real artwork would otherwise be required.

---

## 🚨 Spoiler Policy

Re:ZERO contains story information that can significantly affect a viewer's experience.

DRS therefore aims to separate information by story progression.

Future archive organization may use labels such as:

- Season 1
- Season 2
- Season 3
- Later material

Visitors should always check spoiler labels before opening protected sections.

## 🚀 Running the Website

Because DRS is currently static, you can open `index.html` in a browser to inspect the site.

For development, using a local static server is recommended because it more closely matches how the site will behave when hosted.

---

## 🌐 GitHub Pages

DRS is designed for GitHub Pages.

Typical deployment flow:

1. Create a GitHub repository.
2. Upload the DRS project files.
3. Make sure `index.html` is in the publishing source root.
4. Open the repository's **Settings → Pages**.
5. Select the appropriate publishing source.
6. Save the configuration.
7. Wait for GitHub Pages to publish the site.

The exact GitHub Pages interface can change, so follow GitHub's current Pages documentation when configuring the repository.
